Neon Tides is a top-down 2D open-world crime game set in Port Azure, a sun-soaked coastal city of your own making. Steal cars, outrun the Port Azure PD under a three-star wanted system, and run five story missions for Mara — plus taxi, delivery, and street-race side jobs — with traffic, pedestrians, combat, a minimap HUD, and saves, all in plain Canvas 2D with no libraries and no network.

## Run it

```sh
node serve.ts
```
